# 全站间距规范

本文件是间距的当前规范，优先于旧版 interface-spec.md 中的间距描述。业务布局、控件语义、日期坐标保持不变。

## 层级与数值

| 语义 | 桌面 | 小屏 ≤767px | 用途 |
|---|---:|---:|---|
| 页面边缘 | 32px | 16px | Page Shell |
| 区块间隔 | 24px | 16px | 标题与工作区、工具栏与正文 |
| 卡片间隔 | 24px | 16px | 首页、项目网格、看板列、热力图卡片 |
| 普通卡片内边距 | 24px | 16px | 内容外框、项目卡、统计卡、热力图卡 |
| 小型或嵌套卡片内边距 | 16px | 16px | 看板卡、小日历、未排期 |
| 内容组间隔 | 16px | 16px | 卡片内部不同信息组 |
| 列表行内边距 | 12px | 12px | 首页任务、项目进度、任务列表 |
| 控件与元信息间隔 | 8px | 8px | 标签、图标与文字、同组操作 |
| 属性行纵向内边距 | 8px/边 | 8px/边 | 编辑属性、设置导航排序 |
| 状态层内缩 | 现有 2px | 现有 2px | Hover/Selected 光学留白，不改变布局 |

## 应用规则

- 实现变量集中于 app/globals.css 的 Site spacing semantics 区域，引用现有 ui-space 刻度，不修改刻度值。
- 普通平级卡片用容器 gap；只有现有纵向文档流采用 margin，不能叠加两者制造双倍间距。
- 卡片由外层负责内边距；内部列表行的 padding 用于可点击区域和内容留白。标题与列表内容的对齐要考虑这两层相加。
- 同类工作区共享标题、工具栏和正文间隔。没有工具栏时不保留空占位。
- 小屏只收敛外部间距，不缩小文字或交互目标来塞入内容。
- 日历日期格、周时间格、甘特图列宽/行高、热力图像素格、拖拽命中坐标沿用原值。这些数据区域不套用普通卡片行距。
- Modal 已有 24px 外层内边距和固定操作栏不变，仅属性行增加纵向留白；滚动仍由 Body 承担。
- Popover、Select 菜单沿用共享组件的紧凑选项密度；不使用普通卡片的 24px 作为菜单项间距。
- 不用阴影补间距，不让 Hover 改变布局尺寸，也不通过空白固定高度撑卡片。

## 涉及页面

首页统计/内容卡、任务列表/看板、项目总览、项目内任务、收集箱、日历和甘特图外层、热力图、任务/项目/标签/文件夹/批量改期属性行、设置导航行。

后续新页面按结构语义选择上述变量，不按页面名字新建一套间距。

## 紧凑区域与全站覆盖边界

规范覆盖所有组件类型，但不要求每类组件都改变现有尺寸：

| 类型 | 使用规则 | 本轮处理 |
|---|---|---|
| 日历/甘特图内容外框 | 16px 内边距，工具栏正文间隔24px/小屏16px | 保留原可用横向空间 |
| 日历侧区小卡片 | 12px 内边距，卡片间24px | 保留260px侧区宽度和日期网格密度 |
| Sidebar 导航/项目树 | 紧凑行内边距、2px状态内缩；层级缩进独立 | 保留现有导航布局 |
| Topbar/Toolbar 操作组 | 8px组内、12px组间；空间不足按组换行 | 保留控件高度和原排列逻辑 |
| DatePicker/日期格 | 使用组件自己的cell-size和2px状态内缩 | 不套24px卡片规则 |
| Select/Popover/Dropdown 菜单 | 使用共享primitive原有选项padding和focus规则 | 保留紧凑密度 |
| Button/Input/Switch/Checkbox | 高度与内边距由现有组件variant管理 | 不通过全局padding修改 |
| Modal/Footer | 原24px容器内边距、Body滚动、Footer不收缩 | 保留结构；属性行使用8px上下留白 |
| Badge/Tooltip/图标 | 4–8px微间距，不采用卡片级留白 | 保留现有组件规则 |
| Empty State | 内边距跟随所属容器，不用固定大高度补空白 | 不新增高度 |

复杂工作区的响应断点、拖拽、Resize、日期格坐标均不由普通页面间距变量控制。若普通规范与可用空间冲突，采用紧凑语义，不新增页面专属补偿margin。

## 圆角规范（2026-09-12 上线检查）

| 语义 | 圆角 |
|---|---:|
| 主工作区外框、弹窗 | 16px |
| 嵌套卡片、筛选面板、浮层 | 12px |
| 按钮、输入框、列表悬停状态 | 8px |
| 小型标记 | 4px |
| 胶囊切换、圆点 | 保持全圆角 |

重复组件引用共享圆角变量。日历日期选中态维持正方形，行列与拖拽坐标不受普通卡片规范影响。

## 首页等尺寸卡片

首页四个内容板块采用等宽网格、统一高度：桌面 360px，≤767px 为 320px。内容区独立滚动，外框保持圆角。统计卡片也使用等宽、等高网格。此处固定高度是明确的首页展示要求，不推广到其他页面。

## 样式维护

当前样式统一由 app/globals.css 提供。旧 dayframe-theme.css 已合并并删除；新规则优先修改对应组件的现有声明，避免继续追加历史覆盖层。动态日期范围和颜色类继续保留。

## 动效规范

动效统一维护在 globals.css 的 Motion system 区域，不追加历史主题覆盖。

| 场景 | 时长 | 方式 |
|---|---:|---|
| 悬停、按压、关闭 | 120ms | 颜色与透明度反馈；点击区域保持固定 |
| 下拉菜单、浮层进入 | 160ms | 淡入与轻微缩放 |
| 页面、筛选进入 | 180ms | 透明度变化，不移动日程坐标 |
| 文件夹展开 / 收起 | 180ms / 120ms | 按真实内容高度过渡 |
| 弹窗进入、侧栏、进度更新 | 220ms | 轻缓收尾 |

首页卡片同时出现，不逐个延迟。系统“减少动态效果”或 motion=off 时禁用动画、过渡及平滑滚动。拖拽过程中禁用工作区动画与过渡，日期格、任务条和缩放端点保持即时跟随。

视图切换即时替换内容，不播放整块入场动画；只构建当前视图。日期渲染窗口根据可视宽度保留两侧缓冲，兼容宽屏和浏览器缩放。

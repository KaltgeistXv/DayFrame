# pat-mi 页面与交互结构

## 页面职责

| 入口 | 职责 | 展示方式 |
| --- | --- | --- |
| 首页 | 了解今日安排、待整理任务与需要关注的进度 | 固定概览卡片 |
| 收集箱 | 整理尚未排期的任务 | 列表 |
| 全部任务 | 管理任务、排期、筛选追踪状态、记录每日投入 | 列表 / 看板 / 日历 / 甘特图 |
| 项目 | 管理项目归属、文件夹和整体排期 | 项目概览 / 甘特图；任务日历；项目内采用相同的四种任务视图 |
| 设置 | 管理名称、默认页面、导航顺序、显示、数据备份 | 工作空间 / 界面 / 数据备份 |

追踪是任务属性，不再是一个独立页面。旧版追踪跳转进入“全部任务”的追踪筛选。首页的追踪摘要保留，详情进入全部任务。

## 一致的交互规则

- 列表、看板、任务甘特图共用搜索、追踪范围、完成状态、标签和优先级筛选。切换视图保留筛选；切换模块重置范围，隐藏的筛选有摘要和清除入口。
- 用户拖拽、拉伸或编辑日期定义原计划；系统依当前日期计算顺延。日期投影不复制数据库任务，不生成虚假的投入记录。
- 甘特图与日历以连续横条显示原计划和顺延，并在有真实投入记录的日期加深颜色。
- 打卡表格只显示计划开始至今天的可记录日期，完成后截止完成日。未排期、未来日期不生成空白打卡格；重新排期前已保存的历史记录继续显示。
- 打卡表示投入，不表示完成。完成任务计入完成当日的打卡，并保留已有备注、时长。撤销打卡可通过通知恢复。
- 全天任务与未排期任务明确区分：前者有日期、没有具体时间，后者没有日期。
- 项目归属只在有项目时显示。全局筛选不改变项目概览的完整统计分母。
- 导入旧备份会移除旧追踪导航、将旧启动页映射至全部任务；任务历史与其他显示偏好保持不变。

## 本轮排查与修复

- 去除独立追踪导航和重复甘特图路由。
- 合并原来的两套设置窗口，保留导航排序、默认启动、显示密度、侧栏隐藏与数据备份。
- 修复备注搜索结果在任务甘特图中被二次过滤的问题。
- 修复隐藏筛选后不易察觉筛选条件、空状态文案错误的问题。
- 修复导航排序时把导航项拖到自身可能错误移动位置的问题。
- 打卡行使用工作空间日期，过滤不可用日期并取消空日期边框。
- 调整工具栏换行、任务元信息、项目卡片自适应列数、窄屏看板、表单保存操作位置与打卡点击区域。

验证采用逻辑测试、React 组件静态渲染、真实本地 API 回归、实际预览 CSS 校验与生产构建；不将这些结果视为浏览器手动拖拽或逐像素验收。

## 日历统一入口

日历已合并到全部任务，内部支持年、月、周、日。年视图点击月份进入月视图，点击日期进入日视图。切换时间粒度保留日期；今日按钮回到今天。项目总览提供任务日历，单个项目也使用同一日历组件。原计划、自动顺延、打卡颜色与任务数据保持一致。

日视图按单日分配列宽，周视图根据可用空间分配七列。视口宽度变化及连续滚动时保持日期与拖拽坐标一致。月、年视图保留未排期拖放入口；旧日历导航与备份入口映射到全部任务。

月视图与周视图使用同一横条与追踪配色。跨天任务每周只显示一条，跨周接续；带时间的任务保留时间与时长。每周复用互不重叠的行，最多展示三行，超出任务按日期显示数量并进入日视图查看。拖动横条以抓取日期计算偏移，原计划两端提供日期调整入口；整条顺延展示仍对应同一个任务。

任务详情为已开启追踪或已有记录的任务提供「任务信息 / 打卡记录」页签。打卡面板与独立打卡窗口复用，可按日期新增、修改进展与时长、删除历史记录；完成当天保留打卡但允许编辑内容。切换页签保留任务草稿，打卡写入后只同步记录与必要的进行中状态，不覆盖正在编辑的原计划。甘特图日期网格跨越打卡行，今日高亮连续显示，未打卡圆圈使用透明背景。

从日历或甘特图日期列打开任务，打卡页签默认定位到点击的日期；跨天横条按实际点击列计算，右键入口同样携带日期。无日期入口默认今天（已完成任务默认完成日）；未来日期保持选中但不提供打卡操作。

全部任务与项目甘特图采用统一的项目分组标题，显示项目颜色、任务数和完成数量并支持折叠。未排期任务归入所属项目，独立任务单独成组；组内保留当前任务排序，拖动排序限制在同组。任务行不再重复项目名称，底部取消重复的未排期任务列表，保留紧凑的取消排期拖放入口。

年、月、周、日共用日历工具栏：左侧日期选择，右侧今天、前后翻页和时间粒度切换。周/日工具栏移至整张日历顶部，避免受侧栏宽度影响。移除浏览/排期/框选模式栏：鼠标拖空白排期，Shift 拖空白框选，修饰键点击多选，Cmd/Ctrl+A 全选当前时段；触屏空白滑动浏览，鼠标中键拖动平移。原有模式偏好不再影响交互。

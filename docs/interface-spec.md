# 界面版式规格

统一定义位于 app/globals.css 的 Workspace specification 区域，新增组件复用 --ui-* 变量。

| 用途 | 规格 |
|---|---|
| 页面标题 | 24 px，600 字重，1.25 行高 |
| 弹窗标题 | 20 px，600 字重 |
| 常规任务、按钮、导航、表单 | 14 px，1.5 行高 |
| 密集日历任务标题 | 13 px |
| 日期、进度、标签等辅助信息 | 12 px，1.4–1.5 行高 |
| 工具栏控件 | 32 px 高，6 px 圆角 |
| 表单控件 | 36 px 高 |
| 卡片 | 8 px 圆角，12–16 px 内边距 |
| 间距 | 4 px 基准；8 / 12 / 16 px 常用间距 |

紧凑模式只缩小列表行距，保留同样字号。时间横条、打卡圆圈维持专用紧凑尺寸，避免改变排期坐标。

首页保留统计区与四个固定模块，不允许编辑模块布局。桌面窗口宽至少 1000 px、高至少 680 px 时，扣除顶栏和页面标题后，四张卡片平均分配剩余高度；超出内容在可键盘聚焦的卡片区域内滚动，并保留查看全部入口。小窗口或文字放大时恢复自然页面滚动，不截断内容。移除重复的工作概览标题与固定 340 px 卡片高度。

验证范围：代码与实际预览 CSS、类型检查、已有逻辑测试及生产构建。未做浏览器逐像素验证。

所有页面以顶部为起点，主内容区最大宽度 1600 px、仅水平方向居中。编辑窗口统一靠上显示。任务详情宽至 760 px，标题、页签与底部保存区固定，中间表单独立滚动；基本属性排列为一行、排期单独分区，标签和精确时长按需展开。打卡编辑与历史记录在宽屏并列，小屏自动堆叠。未保存的草稿与点击日期沿用原有逻辑。
